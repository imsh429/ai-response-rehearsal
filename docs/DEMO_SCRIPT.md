# 5분 시연 순서

1. 대시보드에서 배송 지연 상담을 선택합니다.
2. 고객의 즉시 환불·10만 원 보상 요구를 보여줍니다.
3. 주문 조회로 출고 전 상태와 3일 지연을 확인합니다.
4. 이전 상담 조회로 확인되지 않은 도착 약속을 확인합니다.
5. 정책 조회로 취소/환불, 배송비 환급, 관리자 검토 범위를 확인합니다.
6. 아래와 같이 상담사 답변을 작성합니다.

> 이전 안내와 달라 불편을 드려 죄송합니다. 주문과 이전 상담을 확인했습니다. 현재 출고 전이므로 취소 접수가 가능하며 취소 승인 후 카드 환불은 영업일 3~5일 소요됩니다. 배송비 3000원 환급을 접수할 수 있고, 추가 보상은 관리자 검토로 이관할 수 있습니다. 어떤 절차를 원하시는지 확인하겠습니다.

7. AI 고객의 후속 반박에 실제로 한 번 더 답변합니다. 고정된 시연 응답이 아닌 현재 고객 반응에 맞춰 작성합니다.
8. 상담 종료 후 네 항목 점수와 근거 인용을 펼칩니다. 특정 점수를 미리 약속하지 않습니다.
9. 개선 답변을 확인하고 같은 상황에 재도전합니다.
10. 이전 결과와 점수 및 행동의 차이를 비교합니다. 점수가 반드시 오르는 것은 아닙니다.
11. 관리자에서 실행 소요 시간·실패·실제 사용 토큰을 보여줍니다.
12. LangSmith 연결을 설정했다면 프로젝트에서 `session_id`로 필터링해 고객/평가/코칭 실행을 보여줍니다.

데모 모드를 사용할 때는 화면의 데모 표시를 유지하고, 규칙 기반 점수임을 설명하세요.
