# 평가 근거 오류 수정 적용

화면 오류: 평가의 근거 ID 또는 인용문을 확인할 수 없습니다. 다시 평가하세요.

1. 실행 중인 서버 터미널에서 Ctrl+C로 종료합니다.
2. 이 ZIP을 별도 폴더에 풀고, 그 안의 backend/app/agents.py 파일만 기존 프로젝트의 backend/app/agents.py 위치에 덮어씁니다.
3. 기존 프로젝트 최상위에서 python run.py로 다시 실행합니다.
4. 브라우저를 새로고침하고 훈련 기록에서 기존 상담을 연 뒤 상담 종료하고 평가받기를 누릅니다. 실패한 평가는 상담을 완료 처리하지 않아 다시 평가할 수 있습니다.

설정 파일, 데이터베이스, 의존성은 바꾸지 않습니다. .env와 backend/data는 교체하거나 삭제하지 마세요. 프런트 재빌드나 패키지 재설치도 필요 없습니다.

AI에게 원문을 다시 쓰게 하지 않고 실제 자료의 참조만 선택하게 했습니다. 서버가 원문과 ID를 정확히 연결하고 검증합니다. 잘못된 선택은 한 번 자동 재요청합니다. 반복해서 실패하면 대화는 유지하고 오류를 표시합니다. 자동 교정 호출에는 추가 API 사용량이 생길 수 있습니다.

수정 후 자동 테스트 24개 통과. 실제 OpenAI 키를 제공받지 않았으므로 유료 API로 재실행한 결과는 확인하지 못했습니다.
